# ZeelCloud Mobile App

The frontend mobile application for ZeelCloud, built with React Native and Expo. 

## 🛠️ Tech Stack
* **Framework:** React Native (Expo)
* **Language:** TypeScript
* **State Management:** Zustand
* **Navigation:** React Navigation (Drawer & Bottom Tabs)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/prince026846/zeelcloud_frontend-.git
   ```
2. Navigate to the project directory
   ```bash
   cd zeelcloud_frontend-
   ```
3. Install dependencies
   ```bash
   npm install
   ```

### Running the App
To start the Expo development server, run:
```bash
npx expo start
```
You can then open the app on your physical device using the **Expo Go** app (by scanning the QR code), or press `a` to run it on an Android emulator, or `i` for an iOS simulator.

## 📁 Project Structure
* `/src/screens` - Application screens/pages
* `/src/components` - Reusable UI components
* `/src/navigation` - Routing and navigation setup
* `/src/store` - Zustand state management stores
* `/src/utils` - Helper functions (e.g., PDF generation)
