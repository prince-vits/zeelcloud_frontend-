============================================================
  HOW TO RUN
============================================================

  Metro bundler is already running at: http://localhost:8082

  To open on your phone:
    1. Install "Expo Go" from App Store (iOS) or Play Store (Android)
    2. Run in terminal:
         cd /Users/macbookpro/Downloads/ZeelCloud-develop/ZeelCloudRN
         npx expo start
    3. Scan the QR code shown in terminal with your phone camera

  To run on iOS Simulator:
    npx expo start --ios

  To run on Android Emulator:
    npx expo start --android
